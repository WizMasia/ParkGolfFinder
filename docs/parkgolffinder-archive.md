# ParkGolfFinder 아카이브

이 문서는 이전 작업자가 남긴 골격과 설계 의도를 한 곳에 보관하기 위한 기록이다.
이 저장소를 새로 구성할 때 기준 문서로 사용한다.

## 서비스 목표
- 대한민국 전국 파크골프 시설을 모은다.
- 지역별 시설을 지도에 표시한다.
- 시설 상세와 예약 정보를 함께 제공한다.
- 시설명, 주소, 운영기관, 예약 링크의 정합성을 유지한다.

## 사용자 기능 목표
- 시설 찾기
- 지역 / 운영 / 예약 규칙 필터
- 지도 보기
- 상세 보기
- 예약 정보 확인
- DB 일괄 재구성

## 데이터 설계 원칙
- 공식 운영기관 페이지를 1순위로 본다.
- 공식 예약/시설 안내 페이지를 2순위로 본다.
- 지도/포털/기사 자료는 보조 근거로만 쓴다.
- 시설명보다 주소와 운영기관을 우선 확인한다.
- 주소가 불명확하면 즉시 확정하지 않는다.
- 확정 전 자료는 본 테이블에 넣지 않는다.

## 판정 상태
- `confirmed`
  - 공식 페이지에서 시설명과 주소가 맞는다.
  - 주소의 시군구와 region이 맞는다.
  - 예약 페이지와 공식 페이지가 같은 시설을 가리킨다.
  - 좌표가 지역 범위를 벗어나지 않는다.
- `candidate`
  - 이름은 맞아 보이지만 주소나 운영기관이 애매하다.
  - 공식 페이지가 없거나 약하다.
  - 지오캐시 결과가 지역 경계와 충돌한다.
- `hidden`
  - 주소가 비정상이다.
  - 다른 지역 시설과 섞였다고 판단된다.
  - 사람이 봐도 확정 불가다.

## 재구성 / 재매칭 흐름
1. 원천 수집
   - PARKGOLF24
   - 서울/지자체 공식 페이지
   - 기타 공식 예약/시설 안내 페이지
2. 1차 정규화
   - 공백, 괄호, 표기 흔들림 정리
   - 시설명, 주소, 지역, 운영기관 추출
3. 2차 매칭
   - 시설명과 주소를 함께 확인
   - 운영기관 이름과 페이지 도메인 확인
   - 지역명과 주소 행정구역 확인
4. 판정
   - `confirmed`
   - `candidate`
   - `hidden`
5. 지오캐시
   - `confirmed`만 좌표 저장
   - 주소가 불안하면 좌표 생성 금지
6. 예약 분석
   - `confirmed`만 분석
   - 공식 링크 텍스트를 우선
7. DB 반영
   - `confirmed`만 본 테이블에 반영
   - `candidate`는 별도 저장
   - `hidden`은 비노출 상태로 유지

## 지도 UI 골격
- 카카오 SDK 동적 로드
- 다중 마커 렌더
- 지오코딩 시도
- 실패 시 대체 좌표 사용
